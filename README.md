Проект по машинному обучению (логистическая регрессия, SVM, деревья решений, случайный лес, регрессия, кластеризация) научил меня:

Решать задачи бинарной и мультиклассовой классификации — предсказывать, сделан ли коммит в будни или выходные, на основе извлечённых из временных меток признаков (количество коммитов до и после полудня и т.д.).

Понимать, как работают разные алгоритмы изнутри: логистическая регрессия строит линейную границу, SVM ищет гиперплоскость с максимальным зазором, дерево решений делает последовательные разбиения по признакам, случайный лес усредняет множество деревьев.

Визуализировать границы решений — видеть, где модель ошибается, и интерпретировать её поведение.

Обрабатывать категориальные признаки с помощью one-hot encoding, чтобы подавать их в модели.

Анализировать важность признаков — определять, какие факторы (лабораторная, попытка, пользователь) сильнее всего влияют на предсказание.

Бороться с переобучением — разделять данные на train/test, использовать кросс-валидацию, чтобы честно оценивать качество на новых данных.

Решать задачу регрессии — предсказывать непрерывную величину (среднюю дельту между дедлайном и первым коммитом) по просмотрам новостной ленты и числу коммитов.

Применять методы кластеризации (например, KMeans) для группировки пользователей по схожему поведению без целевой переменной — для последующего персонализированного воздействия.

В итоге я освоил полный цикл прикладного ML: от извлечения признаков и выбора модели до оценки качества и интерпретации результатов. Проект показал, как данные о действиях пользователей превращаются в предсказательные модели, полезные для бизнеса.
